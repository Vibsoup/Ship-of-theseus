# Ship of Theseus Machine

An interactive exploration of identity, continuity, memory, and change.

## Tech Stack
- Python
- Flask
- HTML, CSS, JavaScript

## Run Locally
1. Create a virtual environment: `python -m venv .venv`
2. Activate it: `source .venv/bin/activate`
3. Install dependencies: `pip install -r requirements.txt`
4. Run: `python app.py`
5. Open http://127.0.0.1:5000

## Research Note
This is an exploratory prototype, not a validated psychological instrument. Consider consent, privacy, and research ethics before collecting responses.
